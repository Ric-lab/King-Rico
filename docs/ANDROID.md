# Android: estado atual

O produto disponível é o site e sua instalação como **PWA**, explicada em
[Instalar no celular](INSTALAR-NO-CELULAR.md). Usa o mesmo Google e saldo do site.

Este checkout não contém projeto Capacitor, APK, `app/package.json` ou workflow
Android. `app/` contém apenas `app/scripts/bulbs.json`, dados auxiliares de luzes.
Não executar comandos de build Android como se essa estrutura existisse.

O roteiro antigo está preservado no [histórico](historico/ANDROID-ROTEIRO.md).
Suas propostas de serviços não alteram a decisão atual: Firebase Spark, sem
Cloud Functions ou faturamento Blaze.
