# Visual / layout / 3D

1. Ler o arquivo que REALMENTE vai ao ar (ver `site/routes.json` e o build), não uma cópia.
2. Posições do 3D: usar a câmera e os centros reais do código; não chutar pixels.
3. Mudança visual só é entregue depois de ver: print da prévia ou artefato do teste automático.
4. Estilo inline do design existente; reaproveitar moedas, botões, fontes (Baloo 2, Rammetto One).
5. Contraste e legibilidade para idosos acima de efeito.

Rejeitado:
- Linha premiada "fita de ouro com brilho correndo" (a limpa da publicada é a aprovada).
- Molduras douradas grossas; fundos roxos/pretos atrás dos rolos.
- Feedback essencial de ingresso, líquido e roleta ausente na prévia; conferir o fluxo real também com movimento reduzido.
