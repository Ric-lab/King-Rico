# Skills obrigatórias

Toda tarefa, de qualquer modelo (Claude, Codex ou outro):
1. Ler `00-sempre.md`.
2. Ler a skill da área da tarefa (tabela abaixo).
3. Na resposta final, dizer quais skills foram lidas.
4. Se o dono rejeitar algo, acrescentar uma linha em "Rejeitado" da skill da área, no mesmo commit.

| Área | Skill |
|---|---|
| Qualquer coisa | 00-sempre.md |
| Gerar arte 2D/3D, Meshy | assets.md |
| Jogo novo ou regras/RTP | jogo-novo.md |
| Visual, layout, 3D, rolos | visual.md |
| Commit, prévia, publicação | publicar.md |
| Slot Circus (rolos) | rolos-slot.md |
